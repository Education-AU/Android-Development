We will in this course use Firestore for data persistence.

Firestore is part of Firebase services. 

Firebase is hosting  a lot of cloud services – it’s pretty much like Azure or Amazon Web Services. 

It’s cross-platform and can be used from Android, IOS, Web etc.

We will look at Firestore and authentication as the main services you will use from Firebase.
If you want, you can also look into Cloud Storage as well – for storing/loading files in the cloud.

First, we will look at the practical things concerning creating an account.
