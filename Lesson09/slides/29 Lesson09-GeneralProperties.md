Fire store is a NO-sql  type of database.

It is centered around documents and collections of such.

Documents can be thought of a just json objects basically.

In a document you can have attributes of different types

Types standing out are map, array and geopoint

The map data type just gives the following possibility

```json
{
  "name": {
    "first": "Ada",
    "last": "Lovelace"
  },
  "born": 1815
}
```


Name attribute just contains a map where first and last are keys
and Ada, Lovelace are values (so in effect a Dictionary – keys/values)
