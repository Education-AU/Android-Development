Construct an android app with a button that shows
A state count and that increases the count for
every click.


Beneath the count-button a button that initiates
factorization of the number input in the textfield
below

Under the text field show a list of the prime numbers
from the factorization.

The field input must be validated and if erroneous
an error must be presented beneath the input field
in color red

Implement in such a way that the count is unblocked
