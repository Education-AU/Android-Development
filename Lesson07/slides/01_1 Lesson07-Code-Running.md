#### Notice when running coroutine code from slides:

The coroutine-debugger adds output information about the coroutine running the code, the thread it is running on and the
coroutine number. This is very useful for understanding how coroutines are scheduled and executed.

In some examples the code in the slides is run and in other examples the code is loaded from assets to keep the slide
code compressed and readable. The code is run in the same way, but the code in the slides is easier to read and
understand.
