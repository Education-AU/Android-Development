Most general purpose Apis we encounter in our daily programming lives are exposing an Http based Api

Often these Apis are implemented in the spirit of the REST standard.

To contact such Apis we need some tool to help us do that in a structured manner.

So typically, one will resort to some suitable library that satisfies these requirements

In our case we will use *ktor*. A library that is designed to be used in a coroutine context and is very well integrated
with the Kotlin language.

So we will use the *Ktor* http client as an alternative to ex. *Retrofit* because it has a more comprehensive
documentation site and is Kotlin based.

Documentation: https://ktor.io/docs/welcome.html
