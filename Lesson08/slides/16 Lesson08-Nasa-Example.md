The Api I pursue in this example is APOD (Astronomy Picture of the Day) from NASA.

At https://api.nasa.gov/ you can find different Apis

An api key is no longer necessary it seems

There is some confusion about the base url.

The base url I use is a GET from base url: https://science.nasa.gov/wp-json/wp/v2/apod-basic/

To get  data from a specific date you can use the following url: https://science.nasa.gov/wp-json/wp/v2/apod-basic/240601

With date format yyMMdd
