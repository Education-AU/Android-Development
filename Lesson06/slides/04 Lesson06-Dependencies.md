<div class="center-left">
To us the compose navigation framework you need to add dependencies in toml file.

```
navigation="2.8.8"
androidx-navigation = { group = "androidx.navigation", name = "navigation-compose", version.ref = "navigation" }

```

And of course to build.gradle file

There might be a newer version of navigation-compose library, so check the latest version in the official documentation.
