The IDE we will be using is also a JetBrains product called **Android Studio**.

Download and install:
https://developer.android.com/studio

Other IDEs could certainly be used, but the Android Studio IDE has been specially developed for this purpose.
So, it seems a natural choice.

When dealing with pure Kotlin we will be using IntelliJ IDEA

Download and install IntelliJ
https://www.jetbrains.com/idea/download/?section=windows

Install JetBrains Academy Plugin from marketplace

A JetBrains Academy tutorial on Kotlin is provided.
