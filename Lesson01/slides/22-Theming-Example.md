We update the theme accordingly

```kotlin
private val DarkColorScheme = darkColorScheme(
    primary = Olive40,
    secondary = Violet40,
    tertiary = Raspberry40,
    background = MidnightPlumBackground,
    surface = MidnightPlumBackground
)

private val LightColorScheme = lightColorScheme(
    primary = Lime80,
    secondary = Lavender80,
    tertiary = BubblegumPink80,
    background = VanillaBackground,
    surface = VanillaBackground
)   
````
