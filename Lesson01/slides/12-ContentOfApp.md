First, we notice the style:

It is NOT like WPF with XAML

The UI components are coded directly in Kotlin source files

As we observe the main file is *MainActivity.kt*,  *.kt* meaning Kotlin source code file.

The name *MainActivity.kt*  is not of any significance

What is an activity:

An activity is an abstraction of a screen. 

And *MainActivity* is your startup screen.

You can of course have several screens in an app, and we will come to that.

One thing we need to notice though, is the function *onCreate*
