Application development used to be in the language **java**.

But the standard is now to develop in the language **Kotlin**.

Kotlin is a language developed by JetBrains and is compiled to run on java virtual machines.

It is a more modern language than Java, and has for that reason, and others, 
become the standard language for android development.

For that reason, a substantial part of this course will be, acquainting yourselves with the Kotlin language.

For that reason a JetBrains Academy course on Kotlin is supplied to you, and you are expected to complete it.

Obviously, we need some help in creating user interfaces and the UI-framework we are going to focus on is written in Kotlin and is called JetPack Compose.

Documentation: https://developer.android.com/jetpack
